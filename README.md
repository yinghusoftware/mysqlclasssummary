极课时间MySQL 进阶训练营学习总结
==============

时光飞逝，转眼间，我已经完成了极课时间MySQL 进阶训练营的学习。这门课不仅让我学到了不少MySQL的具体知识，更让我有机会向老师这样的业界高手学习思维方式，今天，我怀着激动与感激的心情，写下这篇毕业总结。
# 1. 目前在什么岗位做什么？
我目前在某云厂商做开发，主要是提供网络方面的云服务。之前是作数据存储方面的开发，曾经开发过几款业界最著名的数据存储系统。
# 2. 为什么选择报名学习此训练营？
MySQL和我目前工作没有太大关系。我主要是喜欢学习一些技术（我自己从数据存储转到网络也是因为对技术的热爱）。之前买过老师的MySQL体系课，觉得老师内功深厚，加上虽然我现在不太用MySQL,但它是一个非常重要且常有的软件，所以就想跟着老师学一些底层的原理，毕竟好的原件底层逻辑是户通的。
# 3. 课程讲的如何？这个课程你的收获是什么？
我很喜欢老师的风格。整个课程节奏合理，没有任何浮夸的语言。老师不愧是业界高手，对MySQL的了解事无巨细，任何问题都让人感觉信手捻来。我学到了不少细节和底层原理。虽然这些细节可能对我来说没有马上应用的地方，但底层原理让我了解和记忆这些细节非常有帮助。我发现其中不少道理和我以前做数据存储开发时的道理是相通的。
# 4. 学完这个课程有没有帮我解决工作中的问题？
我以前的工作用到过，我目前的工作并不需要MySQL,但我相信今后一定还会用到。不管目前工作有没有用到，整个过程都让我收益匪浅。

毕业并不是终点，而是新的开始。
